# Study Articles

This directory organizes the literature used in the research project. Original
PDF files are stored locally in `pdfs/` and ignored by Git. Reading notes belong
in `notes/` and should be committed so the analysis remains reproducible.

## Suggested note contents

For each work, record its research question, dataset, method, principal results,
limitations, and relevance to this project. Include page numbers when referring
